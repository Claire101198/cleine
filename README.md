# Daylight Study

A calm, cross-platform study companion for iOS and Android. Plan a few daily tasks, focus with a 25- or 50-minute timer, and see your study streak and weekly focus time.

## Get started

1. Install Node.js and the Expo Go app on your phone.
2. Run `npm install`.
3. Run `npm start` and scan the QR code with Expo Go.

Use `npm run ios` or `npm run android` to open the app in an available iOS or Android simulator.

Your task list, focus sessions, and streak history are stored locally on your device.
